Rules for this repository live in `AGENTS.md` (canonical for every agent). Read it first, then
the nearest package `AGENTS.md` (`packages/core/AGENTS.md`, `apps/client/AGENTS.md`).

`.gemini/settings.json` already lists `AGENTS.md` as a context file, so Gemini CLI and
Antigravity load it automatically. Tool setup: `docs/agents/tool-setup.md`.
