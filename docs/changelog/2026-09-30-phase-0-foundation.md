# Phase 0 — documentation and harness foundation

**Purpose.** This is the complete record of the Phase 0 change set, produced by the lead
architect with AI agents on 2026-09-30 against scaffold commit `ab6dd74`. Nothing in this PR
adds game code or dependencies. Decisions that resolved contradictions were made by the
product owner (Sam Holtzman) and are recorded as ADRs 0003–0009. The critical assessment that
motivated the changes is `docs/reviews/2026-09-30-scaffold-review.md`.

## Not changed on purpose

- No dependencies added or upgraded; `package-lock.json` untouched.
- No TypeScript, ESLint (other than the scripts globals block), Vitest threshold, hook or CI
  behaviour weakened.
- `packages/core/AGENTS.md` and `apps/client/AGENTS.md` unchanged: their folder tables are
  still accurate for the scaffold; Phase 1 updates them when folders appear (rule in
  `02-code-structure.md`).
- The `feat/map` branch was not modified; review notes are in `06-map-and-minimap.md` and the
  scaffold review.

## How this was verified

`npm run check` (format, lint, typecheck, knip, tests with coverage, build, docs check) was run
in the authoring environment; the result is recorded in `docs/plan/PROGRESS.md`. CI on the PR
repeats it on ubuntu, macOS and Windows.
