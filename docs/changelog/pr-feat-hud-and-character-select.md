# PR: feat/hud-and-character-select

**Purpose.** The record for the pull request of `feat/hud-and-character-select`, which builds
character select and the HUD from the owner's Figma frames. The branch was built from a plan, its
work packages and several review rounds that live outside the repository, in the coordinating
session's working folder (`eternalus-agent-work/hud-charselect/`). Their ids are cited in code
comments, docs, `INBOX.md` and `PROGRESS.md`, and `PROGRESS.md` entries are never rewritten
(ADR 0011), so this file defines them (build ruling OD-35, listed in
[reference 15](../reference/game-design/15-figma-frames-and-creative-decisions.md#appendix-the-build-rulings)).
It holds the plan's deviation table and a definition of every working id. The pull request's
description (summary, the pre-PR gate results) is written when the pull request opens.

Where to look for the other ids: owner decisions DEC-nn are in the
[owner decisions log](../reference/game-design/13-owner-decisions-log.md); register rows CD-nn and
build rulings OD-nn in
[reference 15](../reference/game-design/15-figma-frames-and-creative-decisions.md); the owner's
items HC-xx and the edit-table rows T-nn and A-1, A-2 in `INBOX.md` (HC-T1; the rows already
applied are listed below); requirements FR-nn
and NFR-nn in [the MVP requirements](../requirements/06-mvp-requirements.md); open questions OQ-nn
in [reference 12](../reference/game-design/12-open-questions.md); the UI enhancements UE-nn in
[the UI enhancements plan](../plan/ui-enhancements-plan.md); the sprint-1 audit's ids (such as AS-7,
AC-25 and A22-4) in [its review](../reviews/2026-10-09-sprint-1-audit.md).
