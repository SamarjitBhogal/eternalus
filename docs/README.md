# Eternalus documentation map

Everything about how Eternalus is designed, planned and built lives here. Root files stay
short on purpose: `AGENTS.md` (rules for agents and a good summary for humans),
`CONTRIBUTING.md` (conventions), `README.md` (quick start), `INBOX.md` (product-owner ⇄ agent
queue). Every document below carries YAML frontmatter (`title`, `description`, `audience`,
`status`, `owner`, `last-reviewed`, `tags`, optional `paths` and `related`) so that a
task-focused agent can find the document that governs the files it is about to touch
(`grep -l "paths:" docs/**/*.md`). ADR 0008 fixes this structure.

## How to navigate

| You want to…                              | Start at                                                                     |
| ----------------------------------------- | ---------------------------------------------------------------------------- |
| Understand the game                       | [reference/README.md](reference/README.md) → `game-design/`                  |
| Know what the MVP must do                 | [requirements/06-mvp-requirements.md](requirements/06-mvp-requirements.md)   |
| Understand how the code is structured     | [architecture/README.md](architecture/README.md) → `02-code-structure.md`    |
| Add something ("new idea? add a class")   | [architecture/17-extension-recipes.md](architecture/17-extension-recipes.md) |
| See what happens when                     | [plan/README.md](plan/README.md) and the phase docs                          |
| Run or review an AI agent                 | [agents/README.md](agents/README.md)                                         |
| Branch, PR, merge                         | [process/git-workflow.md](process/git-workflow.md)                           |
| Change a guardrail                        | [process/guardrails.md](process/guardrails.md) then an ADR in `decisions/`   |
| See why something was decided             | [decisions/](decisions/)                                                     |
| See what changed and why                  | [changelog/README.md](changelog/README.md)                                   |
| Check the evidence behind a design choice | [research/README.md](research/README.md)                                     |

Folder roles: `plan/` = when; `architecture/` = how; `requirements/` = what and why; `reference/` =
the game design (vision) plus suggestions; `research/` = evidence with citations; `process/` =
how we work; `agents/` = the harness for AI tools; `decisions/` = ADRs; `changelog/` = what
changed. Keep the index below generated: `npm run docs:index` rewrites it and `npm run docs:check`
(part of `npm run check`) fails when it is stale, when a link is broken or when frontmatter is invalid.
